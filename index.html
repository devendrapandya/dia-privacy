Dia – Privacy Policy

Dia is a personal assistant used by one person, its owner, for their own accounts. It is not offered to the public.

What Dia accesses

With the owner's permission, Dia reads (read-only) the owner's Gmail messages, Google Calendar events and Google Contacts, so it can answer the owner's questions about them. Dia cannot send, delete or change email, events or contacts.

How the data is used

  • Data is used only to show the owner answers and summaries they ask for.
  • Data is never sold, shared with third parties, used for advertising, or used to train AI models.
  • To answer a question, relevant excerpts are sent to the AI model provider (Anthropic) under its commercial API terms, which do not allow training on this data.

Storage and security

Sign-in tokens and any stored excerpts are encrypted (AES-256-GCM) on a private server controlled by the owner. Passwords, one-time codes and card numbers are removed before anything is stored.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, which also stops all further reading. Stored data is deleted on request of the owner.

Dia's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
